# 页面使用与计算说明

## 页面如何使用

先选择顶部的持股模式，再点击左侧四张策略卡中的一张。拖动右侧股价滑块，或者点击50、75、100、125、150五个快捷价格按钮，查看到期时的结果。

左侧每张卡片上方是参数标签，下方是策略解释。左下方把股票盈亏、期权盈亏和最终净损益列成算式。右侧上方列出成本、最大收益、最大亏损和当前模拟到期损益；中间是曲线与滑块，下方是当前情形的账单解释。

图表通过滑块联动；图表本身没有拖动行情曲线的功能。

## 颜色如何对应

| 颜色 | 含义 |
| --- | --- |
| 白色 | 当前股价等基础信息 |
| 黄色 | Call 看涨行权价120 |
| 蓝色 | Put 看跌行权价80 |
| 红色 | 支付权利金、亏损 |
| 绿色 | 收取权利金、盈利 |
| 紫色 | 含权利金的成本或临界价 |

策略卡说明中的金额采用对应颜色。图表中的 Put 拐点用蓝色，Call 拐点用黄色，成本标记用紫色；损益数字按正负区分颜色。

## 固定参数

| 参数 | 数值 |
| --- | ---: |
| 初始股票成本 | 100 |
| Call 行权价 | 120 |
| Put 行权价 | 80 |
| 初始权利金，每股等效单位 | 5 |
| 可模拟的到期股价 | 40至160，步长1 |
| 图表纵轴计算范围 | -95至95 |

超出纵轴范围的曲线会被限制在边界显示。因此，顶部和左下方的数值可能超过图中可见范围；不能仅凭曲线边界判断风险已经封顶。最大收益、最大亏损标签是对更完整价格范围的策略概括，不局限于滑块40至160的范围。

## 四种期权的到期损益

令 S 为到期股价。以下均为每股等效单位，未计费用。

| 期权 | 到期净损益 |
| --- | --- |
| Long Call | max(S - 120, 0) - 5 |
| Short Call | 5 - max(S - 120, 0) |
| Long Put | max(80 - S, 0) - 5 |
| Short Put | 5 - max(80 - S, 0) |

在持股模式下，再加上原有股票的损益 `S - 100`。不持股模式下，原有股票损益为0。

例如，持股加 Long Put、到期股价50时：股票损益为-50，期权损益为+25，组合净损益为-25。

## 数量匹配与备兑看涨

页面把合约缩小为每股等效单位，便于理解。若换算到一张对应100股的标准股票期权，相关股票数量、权利金、总损益都要按100股换算。

持股加 Short Call 的“最多赚25”，以股票数量足额覆盖卖出的期权、股票初始成本100、Call行权价120、收到权利金5为前提。股价大涨后，已有股票可直接用于交付，不需要按上涨后的市价重新买入。

“最多赚25”不表示保证盈利：若到期股价50，股票亏50，权利金收入5，组合仍亏45。

如果现实账户只有1股，却卖出一张对应100股的期权，其余99股未被股票覆盖，不适用这张足额备兑策略卡的风险结论。实际能否开仓以及保证金、借股、指派后的处理，都受券商规则约束。

## 到期损益与到期前平仓

当前网页只实现到期损益，没有实现到期前的期权估值。页面里的5是买入或卖出时的原始权利金，不表示期权在整个持仓期内始终只值5。

到期前，期权市场价格包含内在价值和时间价值，受股价、剩余时间、隐含波动率等因素影响。持有 Long Call 后卖出平仓的损益，应该按“卖出期权所得减去原始买入成本”计算；与行权买股是不同的退出方式，不能重复计入两笔收益。

到期前价格模拟、期权张数与股票股数独立设置、保证金及资金不足处理，均不属于当前已实现功能。

## 行权措辞的教学简化

页面根据到期股价相对行权价的位置，解释典型的行权和交割经济结果。真实美式期权可能提前被指派；股价刚碰到行权价，不等于系统立即交割。券商截止时间、自动行权、账户资金及合约类型等因素需要另行确认。

## 源码位置

全部应用源码都在 `index.html`：

- `<style>`：原有主题、布局和配色规则。
- `<body>`：策略卡、图表、按钮、滑块及算账区域。
- `<script>`：策略计算、模式切换、说明配色、SVG图表与联动更新。

主要函数包括 `calcOptionPayoff`、`calcTotalPayoff`、`switchMode`、`selectStrategy`、`setPrice`、`renderColoredDescription`、`getMetaInfo`、`buildStory`、`drawChart` 和 `updateAll`。

页面使用“新手秒懂期权 · Options Made Simple for Beginners”作为中英双语标题，动态说明使用“你的期权账单”称呼读者。
